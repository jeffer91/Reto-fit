# Reto Fit Familia

App sencilla para seguir el reto fit en familia con los datos de la báscula RENPHO:
peso, masa muscular, IMC, masa grasa, porcentaje de grasa y puntuación corporal.

**Abrir la app:** https://jeffer91.github.io/Reto-fit/

## Cómo se usa

1. Después de cada pesaje, abre la app y llena **Nueva medición** con los valores del informe.
2. La medición queda guardada en ese teléfono y el ranking se actualiza al instante.
3. Para que toda la familia la vea, toca **Copiar datos** y pega el texto completo en
   [`datos.json`](datos.json) (desde GitHub: abrir el archivo → lápiz ✏️ → pegar → *Commit changes*).
   En un minuto la página se actualiza para todos.

El ranking compara la primera medición de cada persona con la última.
Bajar es avance en peso, IMC, masa grasa y % de grasa; subir es avance en masa muscular y puntuación.
